# JCE_COVID-19
This repository contains the R script used for downstream analysis and visualization of SnpEff-annotated variant call format (VCF) files described in the associated Journal of Chemical Education manuscript.
The workflow processes annotated SARS-CoV-2 VCF files from five datasets representing Japan (JPN), China (CHN), Germany (GMN), the United States (USA), and the United Kingdom (UK). The script extracts variant annotations from the SnpEff ANN field and summarizes predicted variant effects, SnpEff impact categories, and gene-level mutation profiles.
